# Приложение заметок

## Участники

- **Франчук Алексей**
- **Жалтырбаев Адиль**

## Описание проекта

Это приложение для создания, редактирования и хранения заметок. Пользователь может быстро записывать идеи, задачи и важную информацию, а также сортировать заметки по категориям и искать нужные записи.
